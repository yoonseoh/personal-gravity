Personal Gravity 3D 전달용 파일입니다.

중요:
- index.html 파일을 더블클릭해서 file:// 로 열면 3D 모델 로딩이 막힐 수 있습니다.
- 반드시 이 폴더를 로컬 서버로 열어야 합니다.

가장 쉬운 실행 방법:

1. 터미널을 엽니다.
2. 이 폴더로 이동합니다.
3. 아래 명령어를 실행합니다.

python3 -m http.server 8080

4. 브라우저에서 아래 주소를 엽니다.

http://localhost:8080

포함된 것:
- index.html
- assets 폴더: React/Three.js/CSS 번들
- models 폴더: 3D GLB 모델

친구에게 보낼 때:
- personal-gravity-with-3d 폴더 전체를 보내거나,
- personal-gravity-with-3d.zip 압축 파일을 보내면 됩니다.

Personal Gravity Exhibition Viewer

IMPORTANT:
Do not open index.html by double-clicking it.
The 3D model may not load from a file:// URL in some browsers.

Mac:
1. Double-click start-mac.command.
2. If macOS blocks it, right-click the file and choose Open.
3. Open this URL in a browser:
   http://localhost:8080/

Windows:
1. Double-click start-windows.bat.
2. Open this URL in a browser:
   http://localhost:8080/

If port 8080 is already in use, run one of these commands inside this folder:

Mac:
python3 -m http.server 8090

Windows:
python -m http.server 8090

Then open:
http://localhost:8090/

Included files:
- index.html
- assets/
- models/lg-model-room.glb
